# Web Dev I – Lab Assignment 3: Responsive Personal Portfolio Website

## Description
A one-page responsive personal portfolio website built with HTML and CSS.
It uses Flexbox, CSS Grid, media queries, relative units, transitions and
keyframe animations to create a polished and interactive layout.

Built by Verchus Prabhaker.

## Sections
Header, Hero, About, Skills, Projects, Contact and Footer.

## Features
- **Flexbox:** header, hero section, contact form and footer
- **CSS Grid:** skills and projects cards
- **Media queries:** mobile-first design for mobile, tablet and desktop
- **Relative units:** rem, %, vw and vh used for spacing and font sizes
- **Animations:** color-changing "Full Stack Developer" text and fade-in on load
- **Hover effects:** navigation links, buttons, cards and footer links with smooth transitions

## How to View Responsive Behavior
1. Open `index.html` in Google Chrome.
2. Press `Cmd + Option + I` to open DevTools.
3. Click the device toolbar icon (or press `Cmd + Shift + M`).
4. Change the screen width and watch the layout adapt.

## Breakpoints Tested
| Device | Width | Layout |
| --- | --- | --- |
| Mobile | 375px | Hero stacked (text above image), cards in 1 column |
| Tablet | 768px | Cards in 2 columns |
| Desktop | 1024px and above | Hero side by side (image on right), cards in 3 columns |
